## Sobre el proyecto

**DEINT** es mi repositorio para la asignatura de Desarrollo de Interfaces. Aquí guardo los ejercicios, prácticas y proyectos que voy realizando mientras aprendo a crear interfaces con **Flutter y Dart**.

El objetivo es mejorar poco a poco, experimentar con componentes y aprender a construir aplicaciones con interfaces limpias, modernas y funcionales.

## Estructura del repositorio

```text
DEINT/
├── assets/
│   └── images/
└── lib/
    └── main.dart
```

- **`assets/`**: imágenes y recursos visuales.
- **`lib/`**: código fuente de las aplicaciones y sus interfaces.

## Objetivos

- Aprender a diseñar interfaces con Flutter.
- Practicar widgets y componentes.
- Mejorar la organización y legibilidad del código.
- Crear interfaces adaptables y funcionales.
- Llevar un seguimiento de mi progreso.

## Empezar

1. Clona el repositorio:

   ```bash
   git clone https://github.com/Manolilloo/DEINT.git
   ```

2. Abre el proyecto en Android Studio.
3. Configura Flutter y Dart en tu entorno.

> **Nota:** este repositorio contiene principalmente el código fuente y los recursos. Para ejecutar el proyecto como una aplicación Flutter completa también necesitarás los archivos de configuración, como `pubspec.yaml`.
